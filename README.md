## Selected projects

### [German Power Forecasting & Risk Analytics](https://github.com/AndreaCermaria/german-power-forecasting)

Forecasting hourly day ahead electricity prices for Germany and Luxembourg using demand, renewable generation and power plant outage data.

- Quantile gradient boosting with walk forward backtesting to assess forecast accuracy and uncertainty.
- Risk analysis covering Value at Risk, Expected Shortfall and initial margin.
- An interactive dashboard that brings together forecast and risk results.

**[Explore the dashboard](https://andreacermaria.github.io/german-power-forecasting/)** · [View the code](https://github.com/AndreaCermaria/german-power-forecasting)

### [Production Networks & Monetary Policy](https://github.com/AndreaCermaria/eu-prod-net)

Investigating whether the structure of euro area production networks is associated with differences in the transmission of ECB rate changes into bank credit standards.

- Combines OECD production network data with the ECB Bank Lending Survey.
- Uses network concentration measures, panel regressions and network dynamics analysis.

[View the analysis](https://github.com/AndreaCermaria/eu-prod-net)

### [World Cup Data Explorer](https://github.com/AndreaCermaria/dv_app)

An interactive Python Dash application for exploring World Cup data and identifying outliers through visual analysis.

[View the application code](https://github.com/AndreaCermaria/dv_app)
